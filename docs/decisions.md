# ADR-001

## Fuente única de información

Toda la información del usuario vivirá en un único modelo de datos.

A partir de ese modelo se generarán:

- Página profesional.
- PDF.
- Futuras vistas.

Motivo:

Evitar duplicación de información y facilitar la escalabilidad.

Estado:

Aceptado.


Sprint: UI-001

Objetivo:
Crear el componente Button.

Archivos a modificar:
- Button.tsx

Criterios de aceptación:
- Se visualiza.
- Tiene hover.
- Tiene variantes.
- Compila sin errores.
